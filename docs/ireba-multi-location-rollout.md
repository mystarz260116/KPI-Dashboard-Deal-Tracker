# 入れ歯くん3拠点連携 設定変更のお願い

件名：入れ歯くんAPI 3拠点連携に伴う設定変更のお願い

ご担当者様

お世話になっております。

現在、大阪向けに連携いただいている入れ歯くんAPIについて、今後は東京・大阪・福岡の3拠点から連携する予定です。

なお、現在弊社のテーブルに保存されているデータは、すべて大阪拠点のデータとして取り扱います。

弊社より拠点ごとに専用の接続先URLとAPIキーを発行しますので、各拠点への設定をお願いいたします。

| 拠点 | 接続先URL | APIキー |
| --- | --- | --- |
| 大阪 | 別途ご連絡 | 別途ご連絡 |
| 東京 | 別途ご連絡 | 別途ご連絡 |
| 福岡 | 別途ご連絡 | 別途ご連絡 |

送信するJSONの形式や項目に変更はありません。拠点情報はAPIキーから弊社側で自動判定するため、JSONへの項目追加も不要です。

切替にあたり、現在使用しているAPIからの送信を停止していただき、その後、各拠点専用の接続先URLとAPIキーへ変更をお願いいたします。

切替日時は貴社のご都合に合わせますので、ご希望の日時を事前にお知らせください。切替後、各拠点から受注・納品データを1件ずつ送信いただき、弊社側で正常に登録されたことを確認します。

接続先URLとAPIキーについては、準備が整い次第あらためてご連絡いたします。

現行APIの送信停止および設定変更のご対応可否、ご担当者様、切替希望日時をご連絡いただけますと幸いです。

よろしくお願いいたします。
